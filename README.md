# Site Skills

[![skills.sh](https://skills.sh/b/imamalkan-hub/site-skills)](https://skills.sh/imamalkan-hub/site-skills)

Agent skills for an independent portfolio of health directories, home-improvement references and a charter guide. Each skill is a short guide to one site: what it covers, when to use it, and where to start.

Install everything:

```bash
npx skills add imamalkan-hub/site-skills
```

Install one skill:

```bash
npx skills add imamalkan-hub/site-skills --skill findsleepdoctors
```
