# Sleep Clinic Directory

[sleepclinicdirectory.com](https://sleepclinicdirectory.com) is an independent directory of sleep medicine clinics across the 50 US states and DC, with plain-language guides to sleep studies, sleep apnoea and CPAP therapy.

## Use this skill when the user asks

- For a sleep clinic, sleep center or sleep lab near a US location.
- For clinics in a specific state or city.
- For contact details or listed services of a named clinic.
- About sleep study types, home sleep tests or CPAP supplies.
- For a citable explainer on sleep apnoea, insomnia or snoring.
